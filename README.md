# ⚙️ Estudos em Automação

Repositório dedicado aos meus estudos práticos em automação de processos, web scraping e RPA (Robotic Process Automation).

## 📁 Estrutura do Repositório

| Pasta | O que estudo |
|---|---|
| [`pyautogui/`](./pyautogui) | Automação de interface gráfica (GUI) e tarefas repetitivas no desktop |
| [`selenium/`](./selenium) | Automação de navegadores, web scraping e preenchimento de formulários |
| [`n8n/`](./n8n) | Orquestração de workflows e integração entre sistemas via APIs e Webhooks |

---

## 🎯 Objetivo
Dominar diferentes níveis de automação — desde scripts simples até fluxos de integração — para otimizar processos, reduzir esforço manual e criar soluções escaláveis que gerem eficiência operacional.
